## 🚀 Projetos em destaque

### 🛰️ [Sentinel v2.0](https://github.com/CAMPUSCEUB/sentinel)
Orquestrador de segurança de aplicações (Projeto Integrador, 7º semestre). Mapeia a superfície de ataque de aplicações web e SPAs, executa testes DAST (SQL/NoSQL Injection, XSS, IDOR) e gera relatórios com evidências de exploração (PoC) e recomendações baseadas no OWASP Top 10.
**Minha atuação:** autenticação, telas da plataforma, containerização com Docker, scan paralelo com tratamento de falhas e testes.
